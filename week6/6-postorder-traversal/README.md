# 6. Binary Tree Postorder Traversal

## 1. Problem
Return the postorder traversal (Left -> Right -> Root) of a binary tree.

## 2. Approach
Recursively traverse left subtree, right subtree, and then add the root value.

## 3. Time Complexity
- **Time Complexity:** $O(N)$
- **Space Complexity:** $O(H)$

## 4. Reflection / Improvement
Iterative postorder can be achieved using two stacks.
