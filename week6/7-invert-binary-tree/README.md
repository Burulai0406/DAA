# 7. Invert Binary Tree

## 1. Problem
Invert a binary tree by swapping left and right children for all nodes.

## 2. Approach
Recursively swap left and right pointers using a temporary variable.

## 3. Time Complexity
- **Time Complexity:** $O(N)$
- **Space Complexity:** $O(H)$

## 4. Reflection / Improvement
Can be solved iteratively using a Queue (BFS).
