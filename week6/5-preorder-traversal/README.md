# 5. Binary Tree Preorder Traversal

## 1. Problem
Return the preorder traversal (Root -> Left -> Right) of a binary tree.

## 2. Approach
Visit the root node first, then recursively traverse the left subtree and right subtree.

## 3. Time Complexity
- **Time Complexity:** $O(N)$
- **Space Complexity:** $O(H)$

## 4. Reflection / Improvement
Can be implemented iteratively using a Stack.
